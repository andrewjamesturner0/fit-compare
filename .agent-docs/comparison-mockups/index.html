SPNDAT stats comparison — UI mockups

Five options for presenting statistical agreement data (Bland-Altman, TOST, effect size, CCC, RMSE) in the stats panel. All use the project’s existing CSS variables, fonts, and colour palette. The data shown is the same in all five: Assioma Left vs. Assioma Right, which agree well.

Option 1
Verdict Banner + Compact Grid
A coloured verdict banner at the top (green/amber/red) with the TOST outcome, followed by a 2-column grid of stat cards. Most direct and lab-report-like. Good for: getting to the answer fast.
Option 2
Side-by-side Comparison Cards
Left and right file cards with a central delta column showing the bias, a tolerance-bar visual, and the verdict chip. Supporting stats in a row below. Good for: visual balance, showing both files equally.
Option 3
Accordion Expand Details
The existing compact pairwise strip, but each row expands inline on click to reveal the full statistical breakdown. Minimalist, preserves current density, details on demand. Good for: many file pairs, power users.
Option 4
Dense Table Grid
All pairwise comparisons in a spreadsheet-style table. Columns for every statistic, verdict badges in the last column. Most compact. Good for: comparing 3+ files at a glance, data-minded users.
Option 5
Narrative Sentence + Distribution Sparkline
A natural-language summary paragraph with embedded numbers and verdict, a histogram sparkline of the difference distribution with a tolerance band overlay, and stat chips. Good for: readability, sharing screenshots, users who want a story not a table.
